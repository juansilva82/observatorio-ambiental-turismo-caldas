# Observatorio Ambiental de Turismo Caldas

Sitio web del autodiagnóstico ambiental **Huella Verde** para prestadores turísticos, alcaldías y Gobernación de Caldas.

- `index.html` — la página completa (inicio, autoevaluación, resultados y gráficos).
- `config.js` — conexión con la base de datos (Google Apps Script) y enlace a la política de tratamiento de datos.
- `img/` — fotografías.
- `.htaccess` — https obligatorio y caché (Hostinger).

Publicación: Hostinger (hPanel → Avanzado → GIT) despliega la rama `main` en `public_html`.
